配置管理

每台服务器可分配「不同的命令」——在卡片里勾选该机要执行的命令。采集方式支持 SSH(密钥/密码)、本机、模拟。登录密码加密落盘、页面不回显：留空表示沿用已存密码，输入新值即替换。

全局命令清单。每条命令的原始终端输出即留证内容；实时看板的大数值由程序按命令自动识别，无需配置。脚本不内置命令，全部以此清单为准。新增后会自动定位并聚焦到新卡片，可连续添加。

选择「每日定点」则每天在指定时刻执行一次；选择「固定间隔」则每隔 N 分钟执行一次。归档含每台机每条命令的原始输出、清单与 SHA256 校验。

告警只影响实时看板的告警条与卡片颜色，不改变采集与归档留证。程序按命令内容自动识别 CPU（mpstat）、内存（free）、磁盘（df）指标并取使用率百分比；可总开关，也可分别停掉某个指标或调整两级阈值。

指标启用警告阈值 ≥ %严重阈值 ≥ %
CPU 使用率mpstat
内存使用率free
磁盘使用率df

磁盘 df 忽略项：命中的挂载行不参与「最大值」告警，终端原文与归档留证照常保留。留空即不忽略任何行。

阈值填 0–100 的整数；「严重」需大于「警告」，否则保存时自动纠正为 警告+1。停用的指标不产生告警，但数值照常显示在卡片上。

自动截图：定时巡检时用本机 Python+Pillow 把每条命令渲染成原生样式的 PNG，与 .txt / .ansi 一起平铺在「服务器名称」目录下，文件名自带服务器名称与命令名称。需中心机安装 pyte 与 Pillow。
